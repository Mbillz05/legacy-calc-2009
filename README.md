
## Build and Run Instructions

### Building
Compile the source files using g++ with the C++11 standard:
g++ -std=c++11 *.cpp -o calc

### Running
Execute the calculator with the following command-line format.
Example (Loan amount: 100000, Interest: 12%, Tenure: 360 months):
./calc -cp -a 100000 -i 12 -n 360
